Design Decisions
Episode Manager

Seasons are collapsible blocks. Episodes show inline status badges (Live / Hidden). The edit form slides in as a right panel — no page navigation required.

Hide vs Delete

Hidden episodes are faded in the table with a "Show" toggle instead of "Hide." Deleting requires a separate icon — accidental deletions need two different gestures.

Settings Page

Podcast name, tagline, description, accent color (hex + swatch preview), and cover art upload. All on one page — no sub-sections needed at this scope.
